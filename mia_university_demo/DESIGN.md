# Interface direction

A calm financial investigation workspace using SecFlow's white canvas, pale structural sidebar, restrained blue primary actions and subtle borders. Green, amber and red statuses always include text labels. Use aligned amounts, short Romanian explanations and a persistent Simulation indicator. Evidence and historical timeline outrank decorative charts. Navigation collapses below 900 px and tables retain an intentional details path on narrow screens. Keyboard focus is visible, controls are labeled, press feedback is immediate, and reduced-motion, reduced-transparency and higher-contrast preferences are respected. UTC is used for stored events; the UI displays Europe/Chisinau with the zone named. The frontend is React/TypeScript/Vite/Tailwind with local shadcn-style components.
